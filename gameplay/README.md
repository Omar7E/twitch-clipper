# Gameplay filler

Drop your Subway Surfers / GTA clips in this folder as `.mp4` (or .mov/.mkv/.webm).

- Portrait (9:16) footage looks best; anything else is centre-cropped to fit.
- Long files are better — karak picks a **random start point** in each file so
  every clip you render uses different footage.
- Files are assigned to clips round-robin, so 2 gameplay files alternate.
- Audio is muted by default. To mix some in: `--set render.gameplay_volume=0.15`

`_placeholder.mp4` is a generated test pattern — delete it once you add real footage.
