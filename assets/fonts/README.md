# Fonts

Bundled so libass renders the same captions everywhere without a system install
(`ffmpeg`'s `ass` filter is pointed here via `fontsdir`).

- **BebasNeue-Regular.ttf** — Bebas Neue, © The Bebas Neue Project Authors.
  SIL Open Font License 1.1. https://github.com/dharmatype/Bebas-Neue
- **Anton-Regular.ttf** — Anton, © The Anton Project Authors.
  SIL Open Font License 1.1. https://github.com/google/fonts/tree/main/ofl/anton

Both are OFL, so they're fine to redistribute with this repo and to use in
videos you publish or monetise. Switch with `--set render.font='Anton'
--set render.font_file=Anton-Regular.ttf`.
